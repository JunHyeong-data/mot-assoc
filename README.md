# mot-assoc

다중객체추적(MOT)의 데이터 연관에서, **검출 신뢰도가 비용에 도달하는 조건**을 확인한다.

박준형 · 인하대학교 데이터사이언스학과

---

## 질문

트래킹은 매 프레임 검출을 기존 트랙에 짝지어 붙인다. 그 짝짓기는 비용행렬
(트랙 M × 검출 N)을 만들고 헝가리안으로 푸는 방식이 표준이다.

그런데 그 비용에는 **검출이 얼마나 믿을 만한지**가 들어가지 않는다.
SORT는 IoU 하나, DeepSORT는 마할라노비스 + 외형인데 검출 쪽 공분산은
보통 상수로 고정된다.

> 검출별 불확실성을 비용에 넣으면 짝짓기가 달라지는가? 달라진다면 어떤 조건에서인가?

## 어디서 나온 질문인가

야간 사각지대 경보 시스템(BSDsystem-Deepnight)을 만들면서, 경보 판정이
전적으로 트랙 연속성에 의존한다는 걸 알게 됐다. 그런데 매칭 비용을 직접
짜보니 IoU 하나뿐이었다.

## 현재 상태

| 항목 | 지위 |
|---|---|
| 헝가리안은 비용에 행상수·열상수를 더해도 불변 | **증명** (정방행렬. M≠N이면 열상수는 예외) |
| 검출 공분산이 모두 같으면 공분산항이 순수 행상수 → 기여 0 | **증명 + 합성 수치 확인** |
| 개체별 공분산이면 할당이 바뀐다 (합성 93/100) | **합성 수치 관찰** |
| 가림이 길수록 이중중심화 잔차 감소 (1.099 → 0.007) | **합성 수치 관찰** |
| NMS 후보 분산이 실제 위치오차와 상관 있는가 | **미검증 — 실험 1** |
| 실데이터(MOT17)에서 위 성질이 유지되는가 | **미검증** |
| 트래킹 성능이 실제로 오르는가 | **미검증** |

**모든 수치는 현재 합성 실험이다.** 실데이터 검증 전에는 그렇게만 말한다.
