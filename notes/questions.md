- **2026-08-12** — 공분산 역설은 $d^2$ 만 쓸 때 생기고, $\ln\det S$ 를 더해도
  $S < \varepsilon^2$ 인 동안은 여전히 감소한다. 전환점은 $S = \varepsilon^2$.
  즉 정식 비용을 다 써도 현실적 가림 길이에서는 역설이 완전히 사라지지 않는다.
  (`theory/covariance_paradox.py`)

- **2026-08-12** — 헝가리안은 비용에 행상수를 더해도 최적 할당이 불변이다.
  정방행렬이면 열상수도 불변이지만, M<N (검출이 더 많은 실제 상황) 에서는
  열상수 불변성이 깨진다. (`theory/assignment_invariance.py`)

- **2026-08-11** — 위 항목이 절반만 맞았다. 불변성은 **모든 행/열이 배정될 때만**
  성립한다. M<N 이면 열상수가 깨지고, **M>N 이면 행상수가 깨진다** (14×8 에서
  70/1000 만 불변). M>N 은 트랙 중 N 개만 배정되므로 '어느 트랙을 버릴지' 가
  행상수에 의존하기 때문이다.
  따름결과로 **상수 Σ_d 의 기여가 0 이라는 결론도 M ≤ N 조건부다.** 20×10 에서는
  Σ_d 가 상수(행내 편차 4.44e-16)인데도 93/100 시행의 할당이 바뀐다.
  가림 중에는 검출이 줄어 M>N 이 정상이므로, 이 연구가 겨냥하는 구간에서
  전제가 성립하지 않는다. (`theory/assignment_invariance.py` [1],[3])

- **2026-08-16** — **잔차 감소는 배율 현상이 아니라 진짜 정보 소멸이다.**
  헝가리안은 비용 전체 양수배율에 불변이므로 |R| 감소만으로는 나빠진다고 말할 수
  없다. 그래서 신호/잡음을 분해했다 (`theory/residual_snr.py`).
  가림 0→240 에서 **SNR 3.65 → 0.06**, 정답 복원율 0.761 → 0.186 (무작위 0.125).
  10프레임에서 이미 SNR≈1 이다. 신호가 잡음보다 훨씬 빨리 죽는다.

  **그리고 행 단위 정규화는 이것을 되살리지 못한다.** 행 z-점수와 행 순위변환이
  모든 가림 길이에서 원비용보다 **나쁘다** (가림 10: raw 0.455 / z 0.407 / rank 0.374).

  => "순위 보존 정규화로 covariance paradox 를 푼다" 는 이 형태로는 불가능하다.
     살리려면 **할당 비용이 아니라 채택 임계값** 쪽에 적용해야 한다.

  주의: 처음 짠 실험은 물체 간격을 `SEP*scale**0.5` 로 잡아 간격/불확실성 비를

  길이와 무관하게 **고정**해야 한다.

- **2026-08-16** — **현행 칼만에는 검출 쪽 불확실성 통로가 아예 없다.**
  `KalmanFilterXYAH.project()` 가 측정잡음을 `mean[3]` = **트랙의 높이** 에서 만든다.
  ```
  std = [self._std_weight_position * mean[3], ...]
  return mean, covariance + np.diag(np.square(std))
  ```
  즉 S_i 는 i(트랙)에만 의존하는 **순수 행 양**이다. 마할라노비스를 쓰든 말든
  검출이 얼마나 정확한지는 식에 등장할 자리가 없다.
  이것이 "검출 불확실성이 비용에 안 들어간다" 의 정확한 형태다.
  README 첫 문단은 이 문장으로 써야 한다 (score 얘기가 아니라).

- **2026-08-16** — **바타차야로 바꾸면 통로가 생기지만, 정작 필요한 구간에서 닫힌다.**
  Sigma_d 를 상수→개체별로 바꿨을 때 잔차 변화(= 채널세기)와 할당 변경률:

  | 비용 | 가림x1 | x4 | x16 | x64 |
  |---|---|---|---|---|
  | Maha-DeepSORT (현행) | 0% | 0% | 0% | 0% |
  | Maha-perdet (순진한 개조) | 53% | 18% | 10% | **0%** |
  | Bhattacharyya | 95% | 100% | 100% | **100%** |

  로그행렬식 항을 분해하면 `0.5 ln|Sb| - 0.25 ln|St| - 0.25 ln|Sd|` 인데,
  뒤 두 개는 행/열 상수라 기여 0 이고 **할당에 도달하는 것은 결합항
  `0.5 ln|(St+Sd)/2|` 하나뿐이다** (전체 잔차와 결합항 잔차가 2.18e-16 이내 일치).
  이 항은 St >> Sd 이면 `0.5 ln|St/2|` 로 수렴해 순수 행상수가 된다.
  => **가림이 길어지면 바타차야의 통로도 좁아진다.** 채널세기가 0.148 → 0.025.

  연구 문제가 여기서 정해진다: 거리함수를 바꾸는 것만으로는 부족하고,
  **가림 구간에서 Sigma_d 가 Sigma_t 에 눌리지 않게 하는 장치**가 필요하다.
  Maha-perdet 열이 '순진한 개조는 가림에서 죽는다' 는 대조군이 된다.
  (`theory/mahalanobis_vs_bhattacharyya.py`)
