### 8·9번이 어떻게 잡혔나 — exp04 와 곱셈이 안 맞았다

`run_sequence.py` 가 letterbox→원본 배율을 **NMS 가로채기 안에서** 쟀는데,

> **교훈 셋째: 실험이 겹치는 자리는 곱셈으로 대조하라.**
> 두 실험이 같은 양을 다르게 말하면 둘 중 하나가 틀린 것이다.

1. **같은 양을 다른 경로로 한 번 더 재라.**
2. **단위와 크기의 상식 검사가 조용한 버그를 잡는다.**

### MOT17-05 를 갈랐다 — 네 번째 제약이 나왔다

7개 중 유일한 640×480 인데 두 설정 모두에서 χ² 배율이 혼자 튀었다
(우리 495배 대 나머지 32~128, 저자 1840배 대 62~640). 2×2 로 원인을 갈랐다.

| 실행 | gain | χ² 배율 | σ/h |
|---|---|---|---|
| MOT17-02 @640 | 3.000 | 39배 | 0.00407 |
| MOT17-02 @1920 | **1.000** | **38배** | 0.00418 |
| MOT17-05 @640 | **1.000** | **649배** | 0.00092 |
| MOT17-05 @1920 | 0.333 | **83배** | 0.00745 |

- **letterbox 배율 아니다** — MOT17-02 를 배율 1.0 (MOT17-05 와 같은 조건)으로
  돌려도 39 → 38배로 안 움직인다. 산술이면 9배 올랐어야 한다
- **이동 카메라 아니다** — 이동 카메라 넷 중 나머지 셋은 93~125배로 정상
- **장면 고유 성질도 아니다** — MOT17-05 를 `imgsz=1920` 으로 올리면
  **649 → 83배**로 정상 범위에 들어온다

**원인은 검출기에 준 입력 크기다.** 입력을 3배 키우면 `σ/h` 가 **8배** 커지는데
(0.00092 → 0.00745) `ε/h` 는 1.4배만 커진다. 원해상도 640×480 에서는
**검출기가 후보를 지나치게 좁게 뭉쳐 낸다.**

**왜 못 고치는지를 찾았다 (탐색적).** 보정 뒤 z² 중앙값/χ² 중앙값이 모든 모형에서

> 틀렸다" 이다.** UncertaintyTrack 이 "가우시안 가정과 안 맞는 듯" 이라 **추측**한

### 실험 1f — Student-t. **꼬리가 원인이 아니었다. 0/7**

1e 가 지목한 꼬리를 담는 분포족을 줬다. **핵심 설계는 t 를 모든 모형에 똑같이
주는 것** — A 에만 주면 꼬리 유연성 덕에 이기는 게 당연해서 실험이 죽는다.

**T-A 7.45 vs T-C(상자크기) 6.93. T-A 가 이긴 fold 0/7. 만장일치로 진다.**

- 분포족은 **실제로 도움이 됐다** — A 는 −2.03, C 는 −0.96 만큼 NLL 개선.
  t 가 A 를 두 배 더 도왔다. **그런데도 순위가 안 바뀐다**
- **자유도가 격자 바닥에 붙었다** — T-A 는 7 fold 전부 ν=1(코시). 적합이
  코시보다 더 두꺼운 꼬리를 원했다는 뜻이고, 그 최대 유연성으로도 진다

> **"가우시안 가정이 안 맞아서" 는 이제 변명이 안 된다.** 안 맞는 건 사실이고
> (꼬리비 12~213) 고쳐도(t, ν=1) 결론이 그대로다.

|---|---|---|---|
| A (맨 IoU) | **61.00** | 58.80 | **64.04** |
| W-size (정규화 **안** 함) | 51.52 | 57.01 | 47.56 |

**위 표는 중앙값 보정 값이고, 사전 선언은 채택률 맞춤이었다.** 맞춰 다시 재면
**정규화 갈래가 +7.14 올라 결론의 부호가 뒤집힌다** (철회 15번).

### 사전 선언한 절차(채택률 맞춤)로 낸 최종 판정

| 갈래 | HOTA | DetA | **AssA** | 채택률 |

| **A (맨 IoU)** | **61.00** | 58.80 | **64.04** | 96.33% |

> **[1] 과 [4] 가 같은 방향이다.** 통로를 고치기 **전에도 후에도** 상자 크기 σ 가
> DFL σ 를 이긴다. 통로를 고치니 격차가 −0.60 → **−3.93 으로 커진다.**

**관찰 (사후, 주장 아님)**: `s` 가 **검출 상자 크기를 포함**한다. 중심 거리가
같을 때 `w_d` 가 크면 `s` 가 커져 비용이 내려간다 — 트랙이 **더 큰 검출과
짝지어 비용을 낮출 수 있다.** IoU 에는 없는 병리다. 그래도 순효과는 이득이었다.
**다른 정규화를 더 시도하지 않는다** — 사전 선언에 "하나만 고른다" 고 적었다.

### 손해를 어디에 귀속시키는가

`w_dfl − A = −7.96` 중:

| 후보 설명 | 검증 | 몫 |
|---|---|---|
| 임계값 효과 | 채택률 맞춤 | **−10.56 → −7.96 (2.6) 이미 제거** |
| **정규화 부재** | 실험 5b | **약 2.4 (−7.4 중 1/3)** |
| 검정력 부족 | 관문 [0b] | 없음. CV(Σt)=1.52 |
| 검출 차이 | 캐시 재생 | 없음. 비트 단위 동일 |
| **나머지 ≈ 5.0** | — | **통로 자체.** 설명 안 됨 |

**가장 좋은 와서스타인 변형(wn_size)도 맨 IoU 보다 −4.98 이다.**
분포 유사도라는 의미론이 MOT 연관에 안 맞는다 — 그 몫이 ≈5.0 이다.
(선언은 "채택률을 맞춘다"였는데 구현은 "비용 중앙값을 맞춘다"였다.
보정 절차를 사후에 바꾸지 않고, 채택률을 **측정해서** 확인하는 쪽을 택했다.)

**예외 하나**: MOT17-13 에서만 와서스타인이 IoU 를 이긴다 (56.83 vs 51.65).
카메라가 크게 움직이는 시퀀스다. **n=1 이라 주장으로 안 쓴다.**

### 이 판정이 논지에서 하는 일

**두 의미론이 모두 소진됐다.**

| 의미론 | 어떻게 | 실험 | 결과 |
|---|---|---|---|
| **게이팅** (σ 로 상자를 키운다) | 기하 확장 | exp03 | **−4.33 HOTA** |
| **유사도** (σ 를 거리에 넣는다) | 와서스타인 Bures | **exp05** | **−1.08 / −10.56** |

이제 "검출 불확실성을 MOT 연관 비용에 쓰면 좋아지는가" 에 대해
**서로 다른 두 방식으로 통제된 음의 답**이 있다. 소스도 둘(NMS, DFL) 갈았다.
**이건 실패가 아니라 결과다** — 다만 그렇게 쓰려면 표본(장면 7개)이 발목을 잡는다.

### 이어받는 지점 — 실험 5 의 2·3단계 (**완료됨. 기록용**)

1. **비용함수 + 자체시험** (미착수)
   - `W² = ‖ε‖² + tr(Σt + Σd − 2(Σt^½ Σd Σt^½)^½)`
   - **비싼 실행 전에 합성으로 검증할 것** (exp03 `selftest.py` 방식)
   - 함정 1: 갈래별 Σ 를 `E[tr Σ]` 로 규모 맞추기 — **안 맞추면 갈래 차이가
     정보가 아니라 규모가 된다**
   - 함정 2: Σt 는 칼만 P 로 고정 (갈래 무관 + 짝 일관성 원천 차단)
2. **트래커 재생 + HOTA** (미착수)
   - ultralytics BYTETracker 에 비용만 갈아끼운다 (exp00 `sweep.py` 수법)
   - HOTA 는 **UTrack 에 벤더링된 TrackEval** 사용
     (`external/UTrack/tracker/eval/collections/hota.py`)
   - **[0] 먼저**: 갈래 A(맨 IoU)가 exp02 기준선 **64.494 를 ±0.1 로 재현**해야
     한다. 안 되면 배관이 틀린 것이니 **판정하지 말 것**
3. **판정**: 주 종말점 `W-DFL − W-size`, 판정폭 0.3 HOTA

상세는 `experiments/exp05_wasserstein/README.md` (사전 선언 + **수학 감사**).

**2·3단계는 이미 만들어져 있다** (2026-08-17 저녁):
- `wcost.py` — 비용함수. 대각에서 Bures = sum(sqrt(st)-sqrt(sd))^2 로 떨어진다
- `selftest.py` — **8/8 PASS**. 공분산 역설 없음을 구현 수준에서 확인
- `replay.py` — 캐시된 검출을 BYTETracker 에 재생. `get_dists` 만 갈아끼운다.
  **관문 [0b](트랙 간 CV(Σt))를 여기서 잰다**

**전 과정 재현:**
```bash
python experiments/exp05_wasserstein/cache_detections.py   # 약 110분
python experiments/exp05_wasserstein/selftest.py           # 8/8 PASS
python experiments/exp05_wasserstein/replay.py iou w_dfl w_size
python experiments/exp05_wasserstein/accept_rate.py iou w_dfl w_size
python experiments/exp05_wasserstein/evaluate.py iou w_dfl w_size
```

**HOTA 배선에서 한 선택**: seqmap 적재 경로를 **안 썼다.** exp02 가 seqmap 헤더
누락으로 시퀀스를 하나 조용히 잃은 적이 있다. TrackEval 의 **지표 클래스만** 쓰고
적재는 직접 하되, **MOTChallenge 전처리(distractor 매칭 제거 → zero_marked/
pedestrian 필터 → id 재부여)를 소스 그대로 복제**했다. distractor 제거를 빼먹는
재구현이 흔하고 그러면 HOTA 가 몇 점씩 틀린다.

**수학 감사가 바꾼 것 둘** (결과 보기 전에 반영함):
- 관문 [0] 정정: exp02 의 64.494 는 UTrack `botsort` 값이라 ultralytics
  BYTETracker 로 재현 불가. 절대값 대신 **내적 타당성**으로 바꿨다
- 관문 [0b] 신설: Bures 의 비분리항은 Σt 가 트랙마다 달라야 산다.
  CV=0 이면 채널이 완전히 죽는다(합성 확인)

### 열려 있는 것 (실험 5 와 별개)

- **와서스타인의 실패 원인이 고칠 수 있는 것인가** — `‖ε‖²` 을 상자 크기로

  를 가른다. 이게 실험 5 의 가장 자연스러운 후속이다

## 실험 6 — 임계값 레버. **세 번째 통로도 닫혔다** (2026-08-18)

실험 5b 에서 **채택률 보정만으로 HOTA 가 +7.14 움직였다.** exp00 도 "민감도의
원인은 임계값" 이라 했다. 그런데 그건 전부 와서스타인 갈래 얘기다.
**기준선(맨 IoU, `match_thresh=0.8`)에도 여유가 있는가**를 물었다.

### [A]·[B] 관문 — 여유는 전역엔 없고 장면별로만 있다

| | 물은 것 | 답 |
|---|---|---|
| **[A]** | 0.8 이 이미 꼭대기인가 | 전역 최적 0.85 는 **+0.037**. **ByteTrack 기본값이 이미 최적** |
| **[B]** | 꼭대기가 장면마다 다른가 | **다르다.** 0.70~0.98 로 갈리고 신탁 이득 평균 +1.49 |

**이득이 전부 "장면마다 다르다" 에 들어 있다.** 그래서 적응 규칙이 있어야 한다.

### 왜 이 자리를 팠나 — 눈금이 필요 없는 유일한 자리

임계값은 **장면당 스칼라 하나**다. 절대 눈금이 필요 없고 **단조 관계만** 있으면
된다. 그게 실험 1 이 확정한 σ 의 성질이다 — **신호 O**(편상관 0.32, 검출기·해상도
무관), **눈금 X**(χ² 80~562배). 지금까지 우리는 눈금이 필요한 자리(거리 exp05,
칼만 R exp02, 상자 확장 exp03)에 눈금이 틀린 양을 넣어 전부 졌다.

### 그리드를 고쳤다 — 라벨이 경계에 붙어 있었다

`headroom.py` 의 그리드는 상단이 0.95 였는데 **MOT17-10 과 -13 의 최적이 거기
붙어 있었다.** 경계에 붙은 argmax 는 라벨로 못 쓴다. 사전 선언에서 0.98 을
추가했고, **MOT17-13 이 0.95 → 0.98 로 옮겨가며 이득이 1.73 → 4.66 으로 커졌다.**
나머지 여섯은 그대로다. `predictors.py` 의 하드코딩도 정정했다.

> **그런데 MOT17-13 은 0.98 에서도 여전히 그리드 끝이다.** 진짜 최적은 밖에
> 있을 수 있다. 사전 선언한 그리드를 판정 도중에 늘리지 않았다 (철회 15번 교훈).

### LOSO 판정 — **[1] 실패. 레버 2 가 죽는다**

7 fold. 훈련 6개로 예측변수를 **fold 안에서** 고르고(사람이 안 고른다) 중앙값
이분 규칙을 적합해 본 적 없는 1개에 적용했다.

| 갈래 | 임계값을 어떻게 정하는가 | 결합 HOTA | 시퀀스 평균 |
|---|---|---|---|
| **R0** | 0.80 고정 (ByteTrack 기본값) | **61.002** | 56.737 |
| **R1** | 훈련 6개 최적값의 중앙값 (**장면 정보 0**) | 60.966 | 56.629 |
| **R2** | 훈련 6개로 적합한 **예측 규칙** | 60.795 | **56.986** |
| R3 | held-out 자신의 argmax (**신탁**) | 61.894 | 58.228 |

| # | 종말점 | 가중 결합 (주) | 가중 없음 | 판정 |
|---|---|---|---|---|
| **[1]** | **R2 − R0** | **−0.207** | +0.249 | **판정폭 안. 실패** |
| [2] | R2 − R1 | −0.171 | +0.357 | ([1] 실패 시 해석 안 함 — 사전 선언) |
| [3] | R3 − R0 | +0.892 | +1.491 | 신탁 상한 (참고) |
| [4] | σ 계열이 뽑힌 fold | **3/7** | | σ/√area |

**부호가 가중 여부에 따라 뒤집힌다** (실험 5 와 같은 현상, 큰 시퀀스가 지배).
사전 선언한 주 판정은 가중 결합이고, **둘 다 판정폭 0.3 안이므로 결론은 같다.**
부호검정도 5/7, p=0.453 으로 미결이다.

> **신탁 회수율이 가중 −23%, 가중 없음 17% 다.** 규칙이 상한의 대부분을 못 가져온다.

### 이 판정에서 가장 중요한 두 줄

**첫째, 상한 자체가 작다.** 완벽한 신탁도 결합 기준 **+0.892 HOTA** 다.
설령 규칙이 신탁을 100% 회수해도 1점이 안 된다. **레버의 크기가 애초에 작았다.**

**둘째, R1 이 R0 보다 나쁘다** (60.966 vs 61.002). 장면을 안 보고 눈금만
옮기는 것도 도움이 안 된다. 즉 이득은 "0.80 이라는 숫자가 나빠서" 가 아니다.
**[A] 가 이미 말한 것과 같다 — ByteTrack 기본값이 이미 최적이다.**

### σ 는 골라지긴 했다 — 그런데 도움이 안 된다

**[4] σ/√area 가 3/7 fold 에서 뽑혔다.** 눈금이 필요 없는 자리에서 σ 는
후보로 선택될 만큼의 단조 신호를 갖는다. **그런데 [1] 이 실패했다.**

**선택이 불안정하다** (함정 (b) 대로): σ/√area 3, 상자 높이 중앙값 2,
자차운동 2 로 갈린다. 세 가지가 fold 마다 번갈아 뽑히는 규칙은 규칙이 아니다.

> **관찰 (사후, 주장 아님)**: σ/√area 가 뽑힌 3 fold(05·09·13)는 전부 R2 > R0
> 였고, 상자 높이가 뽑힌 MOT17-02 에서 **−3.52** 로 크게 졌다. **n=3 이고
> 사전 선언에 없다.** 다음 실험의 씨앗으로만 적는다.

### 이 판정이 논지에서 하는 일 — **세 의미론이 모두 소진됐다**

| 의미론 | 어떻게 | 실험 | 결과 |
|---|---|---|---|
| **게이팅** (σ 로 상자를 키운다) | 기하 확장 | exp03 | **−4.33 HOTA** |
| **유사도** (σ 를 거리에 넣는다) | 와서스타인 Bures | exp05 | **−1.08 / −10.56** |
| **임계값** (σ 로 장면마다 문턱을 옮긴다) | LOSO 적응 규칙 | **exp06** | **−0.21 (판정폭 안)** |

앞의 둘은 **눈금이 필요한** 자리였고 σ 의 눈금이 틀려서 졌다는 설명이 가능했다.
**exp06 은 눈금이 필요 없는 자리다.** 순위만 있으면 되는 곳에서도 이득이 없다.

> **"σ 의 눈금이 틀려서" 라는 변명이 여기서 끝난다.**
> 실험 1f 가 "가우시안 가정이 안 맞아서" 를 끝냈던 것과 같은 방식이다.

### 함정과 한계 — 사전 선언에 적어둔 것들

- **(a) 라벨의 5/7 이 잡음이다.** 신탁 이득이 09 +0.20 / 04 +0.35 / 02 +0.46 /
  05 +0.55 / 10 +0.65 로 판정폭 0.3 근처이거나 아래다. **이 실험은 검정력이 낮다.**

## 실험 9 — **분석 단위를 바꿔도 천장은 부분적으로만 열린다** (2026-08-18)

설계 계산(exp07)이 갈래 2 를 "유망하다" 고 적었다. **그게 정말 되는지 따졌다.**
사전 선언 `experiments/exp09_unit/PREREG.md` (커밋 `b9561c3`, 자료보다 먼저).

**이건 트래커가 아니라 설계에 대한 실험이다.** 물은 것:

```
Var(d_s) = Var_true(장면이 실제로 다르다) + Var_meas(재는 데 생긴 잡음)
```

`Var_meas` 가 지배적이면 결정 단위로 정밀하게 재서 천장이 열리고,
`Var_true` 가 지배적이면 **장면 수가 진짜 천장**이다.

### 관문 셋 통과

| 관문 | 결과 |
|---|---|
| **[0a]** Identity 전역 대응 복제 | 벤더링 구현과 IDF1 이 **1e-8 까지 일치** (7시퀀스) |
| **[0b]** 결정 단위 표본 | GT 검출 **53,890 건** (시퀀스당 2,879~24,178) |
| **[0c]** 갈래 간 단위 집합 | **완전 동일** |

### 결과 — 두 쌍이 갈리고, 갈리는 이유가 더 중요하다

**큰 효과 (`iou` vs `wn_size_rate`, 기록 HOTA −4.98)**

| 시퀀스 | 02 | 04 | **05** | 09 | 10 | 11 | **13** |
|---|---|---|---|---|---|---|---|
| IDTP 비율 차이 | +0.105 | +0.035 | **+0.205** | +0.053 | +0.021 | +0.100 | **−0.054** |

`Var_meas / Var(d_s) = 0.259` → 사전 선언표의 **"부분적"**

**작은 효과 (`th080` vs `th085`, 기록 HOTA +0.04)**

`Var_meas / Var(d_s) = 2.463` → **`Var_true` 가 음수다.**
사전 선언표로는 **"열린다"**.

### 그런데 그 판정을 그대로 믿으면 안 된다 — 스스로 만든 진단이 말린다

SE 추정 방식을 바꿔가며 주 종말점을 다시 냈다 (사전 선언이 "iid 값도 같이
적는다" 고 했다).

| SE 추정 | 큰 효과 몫 | 판정 | 작은 효과 몫 | 판정 |
|---|---|---|---|---|
| iid | 0.007 | 천장 | 0.108 | 부분적 |
| 블록 25 | 0.146 | 부분적 | 1.737 | 열린다 |
| **블록 50 (사전 선언)** | **0.257** | **부분적** | **2.498** | **열린다** |
| 블록 100 | 0.362 | 부분적 | 2.275 | 열린다 |

**시퀀스당 블록이 6~11개뿐이다.** 블록 6개짜리 부트스트랩 SE 는 불안정하고,
큰 효과 쪽에서 몫이 블록 길이를 따라 **단조 증가**한다(0.007 → 0.146 → 0.257
→ 0.362) — SE 추정이 아직 안정되지 않았다는 전형적 신호다.

### 그래서 무엇이 결론인가

**하나 — 큰 효과에서는 장면 간 차이가 진짜다.**
어떤 SE 방식을 써도 몫이 **0.36 을 안 넘는다.** 즉 `Var_true` 가 최소 64% 다.
MOT17-05 (+0.205) 와 MOT17-13 (−0.054) 은 어떤 SE 로도 못 메운다.
**장면이 실제로 다르다. 결정 단위로 쪼개도 이건 안 줄어든다.**

**둘 — 작은 효과에서는 가를 수 없다.**
관측된 장면 간 SD(0.00894)가 평균 블록 SE(0.01258)의 **0.71배**다. "전부 잡음"
과도, "약간의 이질성 + 과대추정된 SE" 와도 **둘 다 들어맞는다.**
표본 7개로는 그 둘이 안 갈린다.

> ### **"7개로 충분한가" 를 7개로 답할 수 없다**
>
> 이게 오늘 가장 날카로운 것이다. 분산 분해는 장면 간 산포를 두 조각으로
> 가르는데, **그 가르기 자체가 장면 수에 검정력을 의존한다.** 작은 효과에서
> `Var_true` 가 음수로 나온 것은 "이질성이 없다" 가 아니라
> **"7개로는 못 잰다"** 는 뜻이다.

**셋 — 실용적 결론은 그래도 분명하다.**
가장 낙관적인 몫(0.36)을 그대로 받아도 `Var_true` 가 전체의 64% 다.
필요 장면 수는 그 비율로 줄어드므로 **591 → 약 378.** 가용 자원은 57 이다.

> **자릿수가 안 바뀐다. exp07 의 결론이 그대로 선다.**
> (단 이건 IDTP 분산비를 HOTA 기반 n 에 옮긴 **시사**이지 재계산이 아니다.
>  종말점이 다르다.)

### 판정

**갈래 2 는 부분적으로만 열린다.** 결정 단위로 쪼개면 측정 잡음이 줄어
장면별 효과를 더 정밀하게 볼 수 있지만, **장면 간 이질성이 남고 그게 지배적이다.**
**군집이 7개면 일반화 추론의 자유도는 6 이고, 그건 n 을 53,890 으로 불려도
안 바뀐다** (사전 선언에서 미리 인정한 것).

### 이 실험이 남긴 부산물

- **IDTP 분해가 실제로 작동한다.** Identity 전역 대응을 복제해 GT 검출마다
  0/1 을 뽑았고 IDF1 이 1e-8 까지 맞는다. **장면별 효과를 정밀하게 보는

## 실험 11 (E1) — **가산은 기여 0, 그런데 임계값으로 −3.75 를 낸다** (2026-08-18)

사전 선언 `experiments/exp11_add_vs_mul/PREREG.md` (커밋 `2ac0db4`, 자료보다 먼저).
원고 2절의 설계 제약을 합성(2e-16)에서 **실측**으로 옮겼다.

**설계**: 한 번의 재생 안에서 매 연관 호출마다 `base` / `add` / `mul` 세 비용을
만들고 **셋 다 푼다.** 트래커는 `base` 로 진행하므로 관측이 개입을 안 바꾼다.
섭동은 **일부러 크게** 줬다 — 가산의 기여 0 은 크기와 무관하기 때문이다.

**관문 통과**: 평균 `|Δcost|` = **0.177** (비용 범위 [0,1] 대비 크다), 두 갈래
섭동 크기 비 **1.00**, 연관 호출 **3,344건**. `N≤M` 이 **92.9%**.

### 결과

| # | 종말점 | 값 |
|---|---|---|
| **[1]** | `N≤M` 에서 `add` 의 임계값 전 할당 일치율 | **99.61%** |
| [2] | `N>M` 에서 같은 비율 | **75.42%** |
| [3] | `mul` 의 일치율 | **95.54%** (`N≤M` 만 96.69%) |
| **[4]** | `add` 의 임계값 **후** 채택쌍이 다른 호출 | **56.25%** |
| | (참고) `mul` 의 임계값 후가 다른 호출 | 29.64% |
| | HOTA | base 61.00, **add −3.75**, mul −1.01 |

### ⚠ [1] 이 100% 가 아니었다 — **명제가 아니라 내 조작화가 틀렸다**

사전 선언한 읽는 법은 *"[1] 이 100% 가 아니면 명제나 구현이 틀렸다"* 였다.
**판정하기 전에 원인을 갈랐다** (규칙 2). `diagnose.py`:

| 검사 | 결과 |
|---|---|
| `N≤M` 인데 할당이 달라진 호출 | **12건** |
| 그중 **동점** (`cost_add(P0) == cost_add(P1)`) | **12 / 12** |
| **진짜 위반** (`P1` 이 엄밀히 더 싸다) | **0 / 12** |
| 배정된 쌍 수가 다른 호출 | 0 / 12 |

차이가 **±3.6e-15** — 부동소수 잡음이다. **원래 할당도 여전히 최적**이고,
솔버가 섭동 뒤 **동점 중 다른 최적해**를 골랐을 뿐이다.

> **정리는 성립한다. 틀린 것은 내가 고른 종말점이다.**
> "솔버가 같은 집합을 돌려주는가" 가 아니라 **"최적성이 보존되는가"** 를
> 쟀어야 했다. 후자로는 **12/12, 즉 100%** 다.
>
> **사전 선언한 [1] = 99.61% 를 지우지 않는다.** 조작화 결함으로 기록한다.
> 원고에는 *"할당이 비트 단위로 같다"* 가 아니라
> **"최적성이 보존된다"** 로 쓴다.

### 이게 원래 주장보다 **강한** 결과다

가산은 할당에 **정보를 하나도 전달하지 않는데**(최적성 보존 12/12),
**임계값 통로로 호출의 56%에서 채택을 바꾸고 HOTA 를 −3.75 낸다.**

> **"불확실성을 더하면 중립적이다" 가 아니다. 기여는 0 인데 해롭기만 하다.**
> 곱은 할당 자체를 4.5% 바꾸고 손해가 −1.01 로 더 작다.
> **문헌이 예외 없이 곱을 쓰는 이유에 이제 측정된 근거가 있다.**

`N>M` 에서 75.42% 로 떨어지는 것은 **M,N 조건의 직접 확인**이다 —
열이 다 배정되지 않으면 열상수도 할당을 바꾼다.

## 감사 정정 — **`get_dists` 는 두 번 불린다. 실험 셋이 그걸 몰랐다** (2026-08-18)

## 여지 +3.122 의 성분을 갈랐다 — **연관의 몫은 +2.352 (75.3%)** (2026-08-19)

원고 5.5 가 *"검출 캐시가 같은데 DetA 가 +1.233 오른다"* 는 우려를 **적어만 놓고
크기를 안 쟀다.** 잰다.

### 방법 — 알파별 정확 분해 (근사 아님)

`HOTA_a = sqrt(DetA_a * AssA_a)` 이고 TrackEval 이 알파별 배열을 그대로 준다.
성분을 갈아 끼운다:

| 조건 | HOTA | 기준선 대비 |
|---|---|---|
| 기준선 | 61.002 | |
| **AssA 만 오라클** | 63.354 | **+2.352** |
| 둘 다 오라클 | 64.124 | +3.122 |

**연관 정확도의 몫 75.3%, 출력 정화의 몫 24.7% (+0.770).**

사전 점검 둘을 스크립트 안에 뒀다 — (a) 기준선·오라클 HOTA 가 기록(61.002/64.124)과
맞는가, (b) `sqrt(DetA*AssA)` 재조립이 HOTA 와 일치하는가. 둘 다 통과해야 분해로 넘어간다.

### **+3.122 가 틀린 게 아니다**

완벽한 연관기를 넣으면 **실제로 +3.122 를 얻는다.** 출력이 정화되는 것도 연관이
좋아진 결과다. 다만 구성을 안 밝히면 *"연관 정확도만으로 3.1점"* 으로 읽힌다.

> 더 보수적인 **+2.352** 를 기준으로 삼아도 네 경로(−0.21 ~ −8.90)는 전부 그
> 아래다. **결론 불변, 상한만 보수적으로.**

이건 판정이 아니라 **이미 보고한 수치의 감도 분석**이다. 방향도 안전하다 —
연관의 몫은 +3.122 보다 작아질 수만 있다.

### 오탐 측정 — 원고에 없던 것 셋

| 신호 | AUC | \|dev\| | 높이 통제 편상관 |
|---|---|---|---|
| **박스 크기 σ_C** | **0.3830** | **0.1170** | — |
| NMS 후보 분산 | 0.5698 | 0.0698 | +0.0510 |
| DFL 분포 분산 | 0.4712 | 0.0288 | **+0.1589** |

1. **오탐에 대해서는 신호가 있다.** 5.6 의 결론이 그 population 으로 확장 안 된다
2. **여기서도 상자 크기가 제일 강하다** — 논문 전체 논지와 같은 방향
3. **DFL 은 raw AUC 와 편상관의 부호가 반대다.** 크기가 둘을 함께 몰고, 통제하면 뒤집힌다

> **네 경로는 전부 *매칭 비용*을 다뤘고 *검출 억제* 는 안 다뤘다.**
> 한계 (5) 에 *"본 연구가 닫지 못한 가장 큰 문"* 으로 적었다.

### 안 받은 것

심사자는 "DFL 이 더 강하고 안정적인 신호다" 라고 결론했다. **받지 않는다** —
`σ_C` 자체가 AUC 0.4661 로 같은 방향이고 높이 통제 편상관이 **−0.0220 (거의 0)** 이다.
0.5 미만인 것은 **크기 효과**이지 검출기 불확실성의 정보가 아니다. 그 근거를 5.6 에 적었다.
