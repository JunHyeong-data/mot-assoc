# 원고

`report.tex` — 다중객체추적 데이터 연관에서 검출 불확실성은 활용 가능한가.

## 빌드

한글이 들어가므로 **xelatex + kotex** 이 필요하다. pdflatex 로는 안 된다.

```bash
cd paper && xelatex report.tex && xelatex report.tex
```

두 번 돌려야 목차와 상호참조(`\ref`)가 채워진다. `natbib` 을 쓰지만
`thebibliography` 를 직접 적었으므로 **bibtex 는 돌릴 필요가 없다.**

MiKTeX 이 없으면:

```bash
winget install MiKTeX.MiKTeX
```

## 그림

`figures/` 의 다섯 PDF 는 `experiments/figures/` 의 스크립트가 만든다.
다시 만들려면 저장소 뿌리에서:

```bash
python experiments/figures/fig_signal_transfer.py && python experiments/figures/fig_grid.py && python experiments/figures/fig_criterion.py && python experiments/figures/fig_ceiling.py && python experiments/figures/fig_reversal.py
```

`style.py` 의 `save()` 가 **`figures/` 와 `paper/figures/` 두 곳에 PDF 를
직접 쓴다.** 예전에는 이 줄이 *"복사한다"* 로 사람에게 시켰고, 실제로 여섯 중
둘이 갈려 있었다 (`fig_ceiling`, `fig_signal_transfer` — 풀어 보니 내용은 같고
메타데이터만 달랐다). **손을 없앴다.**

**PDF 는 바이트까지 결정적이다.** `savefig(metadata={"CreationDate": None})`
을 준다. 안 주면 matplotlib 이 실행마다 타임스탬프를 찍어서 **같은 그림을 다시
그려도 바이트가 달라지고**, 그러면 (가) git 이 매번 새 blob 을 쌓고 (나)
*"이 그림 진짜 바뀌었나"* 를 해시로 못 묻는다. **재어 확인했다** — 빼기 전에는
두 번 그린 해시가 다르고, 빼면 같다. 다섯 그림을 두 번 돌려 PDF 10 개 해시가
전부 일치하는 것도 확인했다. **PNG 는 원래 타임스탬프를 안 넣어 손댈 것이 없다.**

**PNG 는 git 에서 제외한다** (`.gitignore` 의 `figures/*.png`). 원고는 PDF 만
쓰고 PNG 는 `.md`·`.tex`·`.py` 어디서도 참조하지 않는데 **추적 바이트의 38%
(1.1MB)** 였다. 눈으로 볼 용도로 만들기만 한다.

`fig_source_channel` 의 **산출물은 지웠다** — 표 2.1 로 옮겨 은퇴한 그림이다.
**스크립트는 남긴다** (규칙 4). 필요하면 다시 그리면 된다.

**번호는 적지 않는다.** 절을 하나 끼우면 `그림 3` 이 `그림 4` 가 되는데 아무도
안 알려준다 — 절 참조에서 이미 두 번 데인 그 병이다. 스크립트 docstring 과
아래 표는 **라벨**로 부른다.

| 파일 | 라벨 | 절 | 무엇 |
|---|---|---|---|
| `fig_signal_transfer.pdf` | `fig:transfer` | 5.1 | 같은 σ, 같은 시퀀스, 다른 평가 대상. 위치 오차는 0 위, 연관 오류는 소스에 따라 갈린다 |
| `fig_grid.pdf` | `fig:grid` | 5.4 | 추정 방식 × 적용 경로 격자. **해상도 띠**를 깔아 어느 칸이 0 과 구별되는지 보이고, **개입 불성립 칸은 파선**으로 갈라 그린다 |
| `fig_criterion.pdf` | `fig:criterion` | 5.4 | 게이팅의 우열이 **맞춤 기준에 따라 부호까지 갈린다.** 주 기준에서 NMS 는 **점이 없다** — 그 대조군이 존재하지 않는다 |
| `fig_ceiling.pdf` | `fig:ceiling` | 5.7 | 여지는 +3.12 있는데 검출기 σ 경로 넷은 전부 0 아래 |
| `fig_reversal.pdf` | `fig:reversal` | 5.8 | 같은 신호, 두 잣대. **박스 크기만 0.5 를 가로지르고 방향이 반대다.** 시퀀스별로는 4/7 이라 탐색적이다 |

### 새 그림 셋은 **원고를 정본으로 삼아 스스로 대조한다**

`fig_grid` 와 `fig_criterion` 이 쓰는 exp19·exp20 은 **요약 JSON 을 안 남긴다**
(track `.txt` 만 남긴다). 값을 손으로 적으면 표와 갈리는데, 그건 이 저장소가
letterbox·NMS in-place·격자 확장 방향에서 이미 세 번 겪은 실패다. 그래서 셋 다
`verify()` 를 두고 **원고에서 같은 숫자를 못 찾으면 그리지 않는다** (규칙 3).

`fig_reversal` 은 한 걸음 더 간다 — 점을 전부 `data/exp21`·`data/exp15` 에서
**다시 계산해** 원고와 대조한다. 행 안 정답률 0.6451 / 0.4720 / 0.4415 와
시퀀스별 4/7 · 1/7 · 2/7 이 실측으로 재현된다. **군집 구간만 원고에서 옮겨
적는다** — exp21 은 rng 를 여섯 번 이어 쓰므로 호출 순서까지 맞춰야 같은 값이
나온다. 사전 등록이 정한 주 판독은 시퀀스별 부호 개수이고 그건 여기서 실측한다.

**`fig_source_channel.py` 는 더 이상 원고에 안 쓴다.** 7×5 격자에 글자를 채운
것이라 **사실 표였고**, 35칸 중 20칸이 비어 지면의 절반이 흰 칸이었다.
**표 2.1** 로 옮겼다 — 추정 방식으로 묶어 정렬하니 패턴이 세로로 읽힌다.
스크립트는 지우지 않는다 (CLAUDE.md 규칙 4).

공통 서식은 `experiments/figures/style.py` 에 있다. 그림은 **지면 크기(6.2in)로
직접 만들고 `\includegraphics` 에 width 옵션을 안 준다** — 배율이 없어야
8pt 로 설계한 글자가 지면에서도 8pt 다.

### 철회 18 — **내가 넣은 논증의 전제가 틀렸다**

위 항목을 처음 쓸 때 나는 두 값을 **방향**으로 옮겨 적었다 — *"주변부로는 작은
박스가 오류 쪽이고, 행 안에서는 큰 박스가 오답 쪽"*. 그리고 그걸 초록·5.8·7.1·
그림 캡션 네 곳에 퍼뜨렸다. **자료를 다시 재니 틀렸다.**

| | 오류 쪽 | 정답 쪽 |
|---|---|---|
| 하위 사분위 | 37.4 px | 70.6 px |
| **중앙값** | **89.8** | **86.8** |
| 90분위 | 200.1 | 222.0 |

**두 분포가 교차한다.** 오류 쪽이 아래에 더 몰리는 건 맞지만 **중앙값은 오히려
높다.** AUC 가 0.5 아래인 것은 이동이 아니라 **교차의 요약**이라 방향이 정의되지
않는다. `notes/progress.md` 철회표 18 번에 적었다.

- **살아남은 것**: 두 값이 우연 수준의 반대쪽에 놓인다는 대비, 그리고 "0.5 를
  벗어난 몫은 검출기 σ 의 몫이 아니다"(그건 편상관 −0.0220 이 지탱한다)
- **원고에 원래 있던 문장이었다** (6.4절). 개정 때 내가 그걸 **5.8 논증의
  머리로 승격시키면서** 문제가 커졌다. 16 번과 같은 부류이고, 더 나쁜 자리다
- `fig_reversal.py` 의 `crossing()` 이 분위수 여섯을 **다시 재어 원고와 대조**한다.
  교차 양상이 깨지면 그리지 않는다. `check_numbers.py` 에 가드 둘을 넣었다 —
  철회된 방향 서술이 되살아나면 0 이 아니게 되고, 교차 서술이 사라져도 잡힌다

> **자기 논증의 전제로 삼기 전에 그 전제를 재라.** 여기서는 AUC 하나를 방향으로
> 옮겨 적은 것이 전제였고, 분위수 여섯을 재는 데 1 분이 걸렸다.

## 요약과 부제를 다시 썼다 (2026-08-21)

### 부제가 본문 한계 (1) 과 어긋났다

> ~~두 경로 안에서 추정 방식을 **가른** 통제 실험~~
> ~~Separating the Uncertainty Source within Two Injection Channels~~

"가른/Separating" 은 **교란이 해소됐다는 주장**이다. 그런데 5.4 절은
*"따라서 교란은 해소되지 않는다"* 로 끝나고 한계 (1) 은 *"결과로 승격하지
않는다"* 로 적혀 있다. 게이팅에서는 주 기준의 대조군이 **아예 존재하지 않고**
부호가 맞춤 기준에 따라 갈린다.

**원고 전체가 규칙 7 스캔을 통과하는데 제목만 그 검사를 안 받았다.**
기존 가드는 영문 `Four Injection Channels` 만 봤고 `Separating` 은 안 봤다.

> **오라클로 여지를 재고, 신호가 거기에 닿는지 먼저 묻는 통제 실험**
> Measuring the Association Headroom, and Whether the Signal Reaches It

7.2 절의 절차를 표지에 올렸다. 이게 이 논문에서 가장 옮겨 쓸 수 있는 기여인데
1,215 줄 중 1,022 줄에 묻혀 있었다. 채널 개수는 **일부러 뺐다** — 넷 중 둘이
MDE 아래라 세는 서술로 되돌아가면 안 된다(가드 `해상도 단서`).

### 요약 — **2,629 자 13 문단 -> 1,655 자 7 문단**

결과 여섯 개가 전부 나오자마자 반박되어 **한 번 읽고 무엇을 밝혔는지 말할 수
없는 상태**였다. 유보를 지운 게 아니라 **층위로 갈랐다**:

| | |
|---|---|
| **주 주장** (추론) | 검출 수준 — 편상관 `+0.322`, 크기 모형에 7/7 패배(`p=0.0156`), Student-`t`·컨포멀로도 안 바뀜 |
| **기술** (추론 아님) | 추적 수준 네 경로 + 오라클 여지 `+3.122` + AUC 와 군집 재분석 |
| **방법론** | 두 잣대가 우연 수준의 반대쪽. 그래서 **순서를 뒤집으라**는 권고 |

빠진 수치는 전부 본문에 있다 — `check_numbers.py` 의 86 개가 그대로 통과한다.
`상한`(정확히 6회)·`네 경로 범위`(4회)·`해상도 단서`(4회)처럼 **자리까지 세는
가드**가 있어서 요약을 줄이면서도 그 넷은 남겨야 했다.

### 손으로 고치다 표지를 조용히 깨뜨렸다 — 가드로 막았다

영문 부제를 편집하면서 LaTeX 줄바꿈 ``\\`` 를 **한 번 잃었다**. `\ ` 는
제어 공백이라 **오류 없이 통과**하고 표지 세 줄이 한 줄로 붙는다.
`check_tex.py` 도 못 잡는다 — **컴파일해야 보이는데 이 기계엔 xelatex 이 없다.**

가드 둘을 넣고 **망가뜨려서 실패하는지 확인한 뒤 되돌렸다** (2 건 -> 0 건):

| 가드 | 무엇을 막나 |
|---|---|
| `철회한 부제 주장` (0회) | `Separating` / `가른 통제 실험` 이 되살아나는 것 |
| `영문 부제 줄바꿈` (1회) | ``\\`` 를 잃어 표지가 한 줄로 붙는 것 |

## 첫 컴파일에서 나온 것 (2026-08-21)

**드디어 조판된 것을 봤다.** 검사기 셋이 0 건인 채로 남아 있던 것들이다 —
**셋 다 지면을 봐야만 보이는 부류다.**

| 무엇 | 어떻게 했나 |
|---|---|
| **링크가 파랑·초록이었다** | `hypersetup` 을 `allcolors=black` 으로. 인쇄 제출본이고, 흑백으로 뽑으면 색 링크가 회색으로 나온다 |
| **볼드가 486 개였다** (약 10 개/쪽) | **205 개로** 줄였다 (약 4.4 개/쪽) |
| **그림이 오른쪽으로 삐져나왔다** | 옛 파일이었다. 지금 다섯은 전부 지면 안이다 — 그리고 **검사기가 폭을 재게 했다** |

### 볼드는 길이가 아니라 **뜻으로** 골랐다

지난번에 짧은 것부터 기계로 벗겼다가 *"측정이 아니라 해석이다"* 같은
**인식 상태 표시**까지 벗겨져 10 개를 되돌렸다. 이번 규칙은 다르다:

> 문단마다 **판정·철회·유보를 나타내는 것을 둘까지** 남기고,
> 그런 것이 없으면 첫 번째 하나만 남긴다. 나머지는 벗긴다.

`철회`, `탐색적`, `측정이 아니`, `말할 수 없`, `성립하지 않`, `승격하지`,
`서지 않는`, `같은 무게`, `우연 수준의 반대쪽` 같은 26 개 표지로 골랐다.
초록은 12 -> 8 개가 되었고 **판정선 관련 넷이 전부 살아남았다.**

### `check_tex.py` 가 그림 폭을 잰다

`includegraphics` 에 width 를 안 주므로 **PDF 의 MediaBox 가 곧 지면 위
크기**다. 본문(451.3pt)보다 넓으면 오른쪽이 잘리는데 **LaTeX 는 경고만 하고
죽지 않아서** 컴파일해도 통과한 줄 안다.

```
그림 figures/fig_signal_transfer.pdf   있음 443pt / 451
그림 figures/fig_reversal.pdf          있음 428pt / 451
```

문턱을 430 으로 낮춰 **넷이 잡히는 것을 확인하고 되돌렸다.**

### 컴파일 전에 반드시 확인할 것 — **판이 맞는가**

첫 컴파일은 **옛 판이었다.** 목차가 `5.4 덧셈과 곱셈`, `5.5 개선 여지` 로
나왔는데 현재 판은 `5.4 격자와 게이팅 대조군`, `5.7 개선 여지` 다.
`fig_ceiling` 이 **그림 5.2** 로 번호 붙은 것도 같은 얘기다 (현재는 5.4).

## 검사기 넷 - 무엇을 잡았고 왜 저장소에서 뺐는가

이 기계에 xelatex 이 없어 컴파일로 잡을 수 없는 것들을 기계로 봤다.
**넷 다 손으로 찾은 실제 오류에서 나왔고, 마지막 실행에서 전부 0 건이었다.**
원고 집필용 내부 도구라 **공개 저장소에서는 뺐다** (2026-08-22).
무엇을 지키고 있었는지는 기록으로 남긴다 - 원고를 다시 손대면 이 넷을 다시 세워야 한다.

| 검사기 | 무엇을 잡았나 | 왜 만들었나 |
|---|---|---|
| `check_tex.py` | 환경 짝, 중괄호, 수식 `$`, `cite`/`bibitem`, `ref`/`label`, **표의 열 개수**, 그림 파일 존재와 **폭** | 표 열 수 불일치는 LaTeX 컴파일 실패 1위다 |
| `check_secref.py` | 절 참조가 **평문으로 되돌아가지 않았는지** + 모든 절에 라벨이 있는지 | 절을 끼울 때마다 번호가 밀렸다 - **6곳, 그리고 2곳.** 원인을 없앴다(아래) |
| `check_numbers.py` | 핵심 수치 86개가 원고에 있는가 + **원고 안에서 일관된가** | 거리 함수 값이 다른 실험 조건이었던 것을 손으로 찾았다 |
| `check_refs.py` | 참고문헌을 **Crossref 로 대조**(학술지·권·쪽·연도) | `solano2024` 에 UTrack 이 아니라 같은 저자의 다른 논문 제목이 들어가 있었다 |

`check_numbers.py` 의 표에는 각 수치의 **출처 실험**이 적혀 있었다.
숫자가 바뀌면 그 실험을 다시 돌려 확인한다 - **그 규범은 검사기가 없어도 그대로다.**

### 절 참조는 `\ref` 로 바꿨다

처음에는 `"5.2절"` 처럼 숫자를 손으로 적었다. 절을 하나 끼우면 뒤 번호가 전부
밀리는데 **아무도 안 알려준다.** 실제로 두 번 났다 - 6.4 신설 때 6곳, 7.2 신설 때 2곳.

검사기로 잡는 것보다 **원인을 없애는 것**이 옳다고 판단해, 평문 참조 **67곳**을
`\ref{sec:장-절}` 로 바꾸고 각 절에 라벨을 달았다. 이제 LaTeX 이 번호를 매기므로
**이 부류의 버그가 생길 수 없다.** 검사기를 빼도 이 상태는 유지된다.

### 참고문헌을 Crossref 로 대조한 결과

인용 하나가 이미 틀려 있었다 — `solano2024` 에 UTrack 이 아니라 같은 저자의
**다른 논문 제목**이 들어가 있었다. 그건 사람 눈으로 잡았고, 나머지를 기계로 봤더니
**심사 논문이 있는데 arXiv 로만 인용한 것이 둘** 나왔다:

| 항목 | 원고에 있던 것 | 실제 게재 |
|---|---|---|
| `lee2024` UncertaintyTrack | arXiv:2402.12303 | **ICRA 2024, 4946–4953** |
| `meng2023` LG-Track | arXiv:2309.09765 | **IEEE Sensors Journal 25, 5282–5293 (2025)** |

나머지 다섯(OC-SORT, GFLv2, UTrack, UCMCTrack, ByteTrack)은 권·쪽을 보강했다.

`kuhn1955`·`milan2016`·`wang2021` 은 arXiv 전용이거나 1955년 논문이라 Crossref 가
엉뚱한 것을 물어 온다. **손으로 확인하고** 스크립트의 `KNOWN_MISS` 에 등록했다.
