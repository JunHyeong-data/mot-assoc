# 실험 17 — **합친 모형은 둘 다 이기는가** (사전 등록)

> **자료를 보기 전에 커밋한다.**

## 왜 이걸 묻는가 — 심사가 지적한 논리 구멍

원고는 두 가지를 나란히 주장한다.

| 절 | 주장 |
|---|---|
| 5.1 | σ 는 **박스 높이를 통제하고도** 위치 오차를 예측한다 (편상관 **+0.322**, 7/7) |
| 5.2 | 그럼에도 σ 만 쓴 모형 A 가 높이만 쓴 모형 C 에 **7/7 로 진다** |

**둘은 모순이 아니다.** 그런데 둘을 합치면 예측이 하나 나온다:

> 높이를 통제하고도 σ 에 정보가 남는다면, **높이와 σ 를 함께 쓴 모형이 둘 다 이겨야 한다.**

**그 모형을 한 번도 적합해 본 적이 없다.** 원고는 σ-만 대 높이-만 경주를 시키고
"σ 는 확률 모형으로 못 쓴다" 고 결론했다. **당연한 후보를 빼놓고 낸 결론이다.**
그리고 이건 이 논문에서 **유일하게 유의성을 얻은 결과**(7/7, p=0.0156)이며
6.2 절이 문헌의 성패를 설명하는 근거이기도 하다.

## 무엇을 적합하는가

기존 두 모형과 **모수 개수를 맞춰** 비교한다.

```
A  (검출별)   Sigma = k * Sigma_d                      모수 (k, nu)     2개
C  (크기)     Sigma = k * diag(h^2, h^2)               모수 (k, nu)     2개
D  (합친 것)  Sigma = k * h^2 * (s / median(s))^g      모수 (k, nu, g)  3개
```

여기서 `s = sqrt(tr(Sigma_d)/2)` 는 검출별 σ 의 스칼라 요약이고, `median(s)` 로
나누어 **무차원**으로 만든다. 지수 `g` 가 σ 의 몫을 정한다:

- `g = 0` 이면 D 는 **C 와 정확히 같다** (σ 를 안 쓴다)
- `g = 2` 이면 σ² 에 비례 (A 에 가까운 쪽)

**D 는 모수가 하나 많으므로 held-out 에서 이기지 못하면 그것만으로 결론이다.**
훈련 NLL 이 아니라 **held-out NLL** 로만 비교한다 (LOSO + 전역 적합 둘 다,
실험 10 과 같은 절차).

## 사전 등록한 평가지표

| # | 평가지표 | 기준 |
|---|---|---|
| **[1]** | held-out NLL: **D 대 C** (짝지은 차이, LOSO) | **주 평가지표** |
| [2] | 같은 것을 **전역 적합**으로 (fold 의존성 없음) | 절차 강건성 |
| [3] | 적합된 `g` 의 분포 | σ 를 실제로 쓰는가 |
| [4] | held-out NLL: D 대 A | 참고 |

**판정 기준 (실험 10 과 같은 자를 쓴다):**

| [1] 결과 | 결론 |
|---|---|
| **D 가 7/7 승 (p=0.0156)** | **원고 결론 2 를 고쳐야 한다.** σ 는 크기와 *함께* 쓰면 쓸모가 있다 |
| D 가 5~6/7 승 | 방향은 σ 쪽이나 유의성 미달. **결론 2 에 단서를 단다** |
| D 가 4/7 이하 | **원고 결론 2 가 선다.** 합쳐도 크기 모형을 못 이긴다 |

**[3] 의 읽는 법:** 적합된 `g` 의 중앙값이 **0.1 미만**이면 적합이 σ 를
사실상 버린 것이므로, [1] 이 어떻게 나오든 **"σ 는 기여하지 않는다"** 로 읽는다.

## 미리 고정하는 것

- **소스는 NMS 후보 분산과 DFL 분포 분산 둘 다** 돌린다. 5.2 절이 두 소스에서
  방향이 반대였으므로 한쪽만 보면 안 된다
- `g` 는 격자 `[-1, -0.5, -0.25, 0, 0.25, 0.5, 1, 1.5, 2]` 에서 고른다.
  **음수를 포함하는 이유**: σ 가 클수록 공분산이 *작아지는* 쪽이 이길 수도 있고,
  그러면 그것도 결과다
- **D 가 이겨도 그것만으로 "σ 를 쓰라" 가 되지 않는다.** 5.3 절의 네 경로는
  여전히 음성이고, 밀도 모형에서 이기는 것과 연관 비용에서 이득을 내는 것은
  다른 문제다. 그 구분을 원고에 적는다
- n=7 이므로 **만장일치만 유의**하다 (CLAUDE.md 규칙 6)
