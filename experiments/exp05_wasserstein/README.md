# 실험 5 — 와서스타인 통로에 DFL σ 를 넣는다 (**사전 선언**)

이론(`theory/divergence_channels.py`)이 **와서스타인만** 세 진단을 통과한다고 했고,
실험 1g 가 **DFL 이 크기모형을 이기는 유일한 소스**라고 했다. 처음으로
**소스와 통로가 둘 다 후보를 통과한 상태**다. 이제 HOTA 로 직접 잰다.

## 왜 이게 결정적인가

지금까지 우리 판정은 전부 **우도**였다 — 대리지표다. 실험 3 이 보였듯
**기하 통로는 σ 를 벌한다** (−3.81 HOTA). 우도에서 −0.1 nats 이긴다고
트래킹이 좋아진다는 보장이 전혀 없다. **이 실험이 그 질문에 직접 답한다.**

## 설계 — 검출을 한 번만 돌리고 트래커만 재생한다

갈래마다 검출기를 다시 돌리면 검출이 미세하게 달라질 여지가 생긴다.
**한 번 캐시하고 트래커만 재생하면 갈래 사이에서 검출이 비트 단위로 같다.**
갈리는 것이 비용함수 하나뿐이 된다. (`cache_detections.py`, exp00 `sweep.py` 와 같은 수법)

검출기는 **저자 가중치 + 포크 설정** — exp02·exp03 의 기준선(HOTA 64.494)과
같아야 숫자가 이어진다.

## 겨루는 갈래

`W²(t,d) = ‖ε‖² + tr(Σt + Σd − 2(Σt^½ Σd Σt^½)^½)` 를 비용으로 쓴다.
IoU 를 대체하는 것이 아니라 **같은 자리에 다른 거리를 넣는다.**

| 갈래 | Σ_d | 무엇을 묻나 |
|---|---|---|
| **A** baseline | — (맨 IoU) | 기준선. exp02 의 64.494 를 재현해야 한다 (**훅 검증**) |
| **W-DFL** | **DFL 분포 분산** | 이 실험의 주장 |
| **W-size** | `c·h²·I` (상자 크기) | **넘어야 할 것 — 이게 NWD 다** |
| **W-NMS** | NMS 후보 분산 | 소스×통로 격자를 채운다 (진단용) |

**`W-size` 가 결정적 통제군이다.** 실험 1e·1f 의 `C` 와 같은 것이고,
문헌에서 **NWD/LQTTrack 이 실제로 배포한 방법**이다. 허수아비가 아니다.

## 사전 선언한 판정

| # | 종말점 | 기준 |
|---|---|---|
| **[0]** | A 가 exp02 기준선(64.494)을 재현하는가 | ±0.1 안. **아니면 배관이 틀린 것이니 판정 중단** |
| **[0b]** | 기준선에서 트랙 간 `CV(Σt)` (수학 감사 (나)) | **CV < 0.05 면 검정력 없음.** 널을 증거로 쓰지 않는다 |
| **[1]** | **W-DFL − W-size** (HOTA) | **> 0 이면 DFL 소스가 통로에서도 낫다** |
| **[2]** | W-DFL − A (HOTA) | 와서스타인 통로 자체가 IoU 를 이기는가 |

**[1] 이 주 종말점이다.** [2] 는 통로 효과이고 [1] 이 소스 효과다.
실험 1g 가 우도에서 본 것이 HOTA 로 옮겨가는지가 [1] 하나에 걸린다.

**판정폭**: exp03 이 −3.81 HOTA 를 "판정폭 0.3 의 13배" 라고 불렀다.
같은 자를 쓴다 — **|ΔHOTA| < 0.3 이면 "차이 없음"** 으로 읽는다.

## 미리 못박는 함정 다섯

1. **Σ 규모를 맞춰야 한다.** DFL σ 는 0.26배 과대, NMS σ 는 80배 과소다
   (실험 1b·1g). 날것으로 넣으면 **갈래 간 차이가 정보가 아니라 규모**가 된다.
   → **각 갈래의 Σ 를 `E[tr Σ]` 가 같아지도록 전역 배율로 맞춘다.**
   exp03 이 확장량을 맞춘 것과 같은 이유다
2. **트랙 쪽 Σt 를 무엇으로 둘 것인가.** 칼만 P 를 쓰면 갈래마다 다른 궤적을
   타서 통제가 깨진다. → **Σt 는 갈래와 무관하게 칼만 P 의 위치 성분으로 고정**
3. **W² 는 IoU 와 눈금이 다르다.** `match_thresh` 를 그대로 쓰면 안 된다.
   → 각 갈래에서 **채택률(매칭 수 / 최적쌍 수)을 A 와 맞추도록** 임계값을 보정하고,
   **보정 전후를 모두 보고**한다. 안 맞추면 통로 효과와 임계값 효과가 섞인다
4. **exp03 의 교훈**: 짝 일관성. 트랙이 검출의 Σ 를 물려받으면 정답쌍이 같이
   움직인다. → Σt 를 칼만 P 로 고정하면(함정 2) 이 문제가 원천 차단된다
5. **1회 실행이다.** 시드 변동폭을 모른다. 판정폭 0.3 미만은 주장하지 않는다

## 이 실험이 답하지 않는 것

- **DanceTrack·MOT20 에서도 같은가** — MOT17 val_half 7시퀀스뿐이다
- **[1] 이 양수여도 p 는 없다** — 시퀀스 7개짜리 HOTA 차이다. 실험 1g 의
  표본 문제(독립 장면 7개)가 여기도 그대로 있다

## 수학 — 대각 공분산에서 Bures 항이 떨어진다

우리 경우 Σ 가 전부 대각이다 (DFL 은 변마다 독립 softmax, 상자크기 모형은
정의상 대각, 칼만 P 의 위치 성분도 대각). 대각이면 행렬제곱근이 원소별이 되어

```
tr(Σt + Σd − 2(Σt^½ Σd Σt^½)^½)  =  Σ_i ( √σt_i − √σd_i )²
```

**표준편차 차이의 제곱합**으로 떨어진다. 싸고 정확하다.
`selftest.py [1]` 이 일반 행렬형과 대조해 **max|diff| = 2.1e-14** 를 확인했다.

## 트래커에 넣는 형태 — NWD 의 사상을 쓴다

`W²` 은 px² 이고 무한대까지 가는데 ByteTrack 비용은 [0,1] 이다. NWD 가 쓰는
지수 사상을 그대로 쓴다: `cost = 1 − exp(−√(W²)/C)`.
`C` 는 **채택률을 기준선과 맞추도록 보정**한다 (함정 3). 닫힌해가 있다.

## 수학 감사 — **결과를 보기 전에** 따진 것 (2026-08-17)

HOTA 를 하나도 계산하기 전에 비용함수의 수학을 감사했다. **셋이 나왔고
하나는 설계를 바꾼다.** 사전 선언을 그에 맞춰 고친다 (자료를 보기 전이므로 정당하다).

### (가) 할당에 도달하는 것은 **교차항 하나뿐**이다

```
Bures = Σᵢ(√σtᵢ − √σdᵢ)²  =  tr(Σt)  +  tr(Σd)  −  2Σᵢ√(σtᵢ·σdᵢ)
                              └행상수    └열상수    └── 유일한 비분리항
```

이중중심화 뒤 남는 것은 `−2Σᵢ√(σtᵢσdᵢ)` 하나다. 나머지는 할당이 안 본다.

### (나) **그 항은 Σt 가 트랙마다 달라야 산다** ← 설계 변경

`σt` 가 트랙 간 상수면 `−2√(σt)·√(σdⱼ)` 가 **순수 열함수**가 되어 사라진다.
합성으로 확인:

| Σt 의 트랙 간 변동 (CV) | \|R(Bures)\| |
|---|---|
| **0.00** | **0.0000** |
| 0.05 | 0.153 |
| 0.20 | 0.624 |
| 0.50 | 1.686 |
| 1.00 | 3.030 |

> **CV=0 이면 Σ_d 채널이 완전히 죽는다.** 즉 이 실험이 무언가를 찾을 수 있는지는
> **칼만 P 가 트랙마다 얼마나 다른가**에 달렸다. 실제로 P 는 상자 크기에 따라
> 변하므로 0 은 아니겠지만, **작으면 이 실험은 애초에 검정력이 없다.**

**따라서 판정 전에 관문을 하나 더 둔다:**

> **[0b] 기준선 실행에서 트랙 간 `CV(Σt)` 를 측정한다.**
> **CV < 0.05 이면 이 설계는 검정력이 없다.** 그때는 [1] 의 결과가 0 으로 나와도
> **"차이 없음"이 아니라 "못 잰다"로 보고한다.** 널 결과를 증거로 쓰지 않는다.

이건 exp03 의 사전 검정력 확인(`power_check.py`)과 같은 역할이다 — **비싼 실행이
원리적으로 무언가를 구별할 수 있는지 먼저 본다.**

### (다) 와서스타인은 **게이트를 넓히지 않는다**

`W² = ‖ε‖² + Bures`. 위치항에 `Σ⁻¹` 이 없다.

| Σt 배율 | 마할라노비스 d² | 와서스타인 위치항 |
|---|---|---|
| ×1 | 69.4 | 625.0 |
| ×64 | **1.1** | **625.0** |

마할라노비스는 64배 불확실해지면 위치 대가가 64배 싸진다(게이트가 열린다).
**와서스타인 위치항은 꿈쩍도 안 한다.**

> **와서스타인은 공분산 역설을 "메커니즘을 없애서" 푼다.**
> 마할라노비스는 과하게 보정하고, 와서스타인은 아예 보정하지 않는다.

### (라) 그래서 Σ_d 의 역할은 게이팅이 아니라 **분포 유사도**다

`Bures` 는 `σd = σt` 에서 **최소 0**이다. 즉 "나와 비슷한 불확실성을 가진 검출"을
선호한다. 이건 "불확실하니 관대해져라"가 아니라 **"불확실성 수준이 맞는 짝을
찾아라"** 다. **다른 종류의 정보다.**

> ### 이것이 실험 5 의 주장을 다시 규정한다
>
> 우리는 **"불확실성 인지 게이팅"을 만드는 게 아니다.**
> **"불확실성을 매칭 특징으로 쓰는 것"**을 시험하는 것이다.
>
> 그리고 이 구분이 논문에 좋다 — **두 의미론이 exp03 과 exp05 로 소진된다:**
> - **게이팅 의미론** (σ 로 상자를 키운다) → exp03, **−3.81 HOTA 로 실패**
> - **유사도 의미론** (σ 를 거리에 넣는다) → exp05, 지금 시험 중
>
> 어느 쪽이 나오든 "검출 불확실성을 연관에 쓰는 두 가지 방식"에 대한
> 통제된 답이 된다.
