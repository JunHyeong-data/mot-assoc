# 실험 18 — **행 안에서 재면 σ 가 정답을 고르는가** (사전 등록)

> **자료를 보기 전에 커밋한다.**

## 왜 — 심사가 논문의 중심 기둥을 겨눴다

원고 5.6 의 AUC 하나에 세 가지가 얹혀 있다: 6.1 의 음의 결과 재해석,
7.1 의 다섯째 결론, 7.2 의 사전 점검 절차. 그런데 심사가 이렇게 지적했다.

> AUC 는 **기준선이 이미 채택한 쌍**을 모집단으로 하고, 쌍을 **독립적으로** 늘어놓은
> **주변부(marginal)** 판별력이다. 그러나 헝가리안이 푸는 문제는 **한 트랙의 행 안에서
> 후보들 사이의 상대 순서**다. 행 안에서 정답과 오답을 가르는 능력이 있어도 전역 AUC 는
> 0.5 에 붙을 수 있고, 반대도 성립한다.

**그리고 원고 안에 반례가 있다:**

| 신호 | \|AUC−0.5\| | 같은 경로(거리 함수)의 ΔHOTA |
|---|---|---|
| DFL 분포 분산 | **0.0429** (더 큼) | **−8.90** (더 나쁨) |
| 박스 크기 σ_C | 0.0339 (더 작음) | **−4.98** (더 나음) |

**같은 경로 안에서 판별력이 더 낮은 신호가 3.93 HOTA 더 좋다.**
7.2 의 사전 점검이 예측하는 순서가 뒤집혀 있다. 게다가 그 σ_C 는 표 2.1 에서
UCMCTrack 의 SOTA 근거로 올라온 신호 계열이다 — **우리 절차를 그대로 적용했다면
UCMCTrack 을 시작 전에 기각했을 것이다.**

## 무엇을 재는가 — 헝가리안이 실제로 푸는 문제로

`틀림_고칠수있음` 은 정의상 **올바른 검출이 같은 단계에 있었다**는 뜻이다.
따라서 사례마다 **짝지어** 비교할 수 있다.

```
각 수정 가능한 오류에 대해:
    j   = 실제로 채택된 **오답** 검출
    j*  = 같은 호출에 있었던 **정답** 검출 (트랙의 GT id 와 같은 것)
    -> sigma(j*) < sigma(j) 인가?
```

이것이 **행 안(within-row) 짝 비교**이고, 헝가리안이 한 행에서 후보를 고르는
문제와 같은 구조다. 분석 단위가 쌍이라 **n=7 제약을 받지 않는다.**

정답 후보가 여럿이면 **트랙과 IoU 가 가장 큰 것** 하나를 쓴다(자료 보기 전에 고정).

## 사전 등록한 종말점

| # | 종말점 | 기준 |
|---|---|---|
| **[1]** | `sigma(j*) < sigma(j)` 인 비율 | **주 종말점** |
| [2] | 같은 것을 박스 크기 `sigma_C` 로 | 기준 비교 |
| [3] | `log sigma(j*) − log sigma(j)` 의 중앙값 | 효과 크기 |
| [4] | 두 소스(NMS·DFL) 각각 | 5.2 에서 방향이 갈렸으므로 |

**판정 기준 (자료 보기 전에 정한다):**

| [1] 비율 | 결론 |
|---|---|
| **≥ 0.60** | **행 안에서는 σ 가 정답을 고른다.** 5.6 의 AUC 가 잘못된 자였고, **원고의 중심 주장을 고쳐야 한다** |
| 0.55 ~ 0.60 | 약하게 고른다. 5.6 에 단서를 달고 7.2 의 사전 점검을 행 조건부로 바꾼다 |
| 0.45 ~ 0.55 | **못 고른다.** 5.6 의 결론이 더 단단해진다 |
| < 0.45 | 반대로 고른다(오답 쪽 σ 가 더 작다). 그것도 결과이므로 그대로 적는다 |

**어느 쪽이 나와도 논문에 이득이다:**
- 분리가 없으면 → "신호가 안 옮겨간다" 가 **훨씬 단단해지고**, σ_C 반례가
  "측정의 문제" 가 아니라 "신호 자체의 문제" 로 정리되며, 7.2 가 방어 가능해진다
- 분리가 있으면 → **더 중요한 발견이다.** 신호는 있는데 네 경로가 전달을 못 한
  것이므로 결론이 "경로 설계 문제" 로 되돌아간다. **그러면 원고를 크게 고친다**

## 미리 못박는 것

- **7.2 의 사전 점검 문장은 [1] 과 무관하게 고친다.** 위 반례만으로도
  *"이 값이 무작위 수준에 가까우면 주입 형태를 아무리 바꿔도 이득이 나지 않는다"* 는
  **일반 명제로 진술할 수 없다.** 관측 진술로 낮춘다
- 퇴화 공분산(σ=0) 검출이 포함되는지 **세어서 함께 보고**한다. 심사 Q3 이 지적한
  대로 5.1 의 +0.322 는 제외하고 잰 값이라 두 수치를 나란히 놓으려면 밝혀야 한다
- 짝이 없는 경우(정답 검출을 다시 못 찾는 경우)는 **세어서 따로 보고**하고
  분모에서 뺀다
