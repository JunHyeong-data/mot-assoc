# 실험 1 — NMS 후보 분산이 실제 위치 오차와 상관 있는가

**이 실험이 관문이다.** 상관이 없으면 "검출별 불확실성을 비용에 넣는다"는
방향 자체를 접는다. 그러니 가장 먼저 한다.

---

## 질문

검출기가 한 물체에 대해 여러 후보 상자를 내놓고 NMS 가 하나만 남긴다.
남기지 않고 **억제된 후보들의 표본 분산**을 보면, 그게 그 검출이 실제로
얼마나 부정확한지를 알려주는가?

$$\Sigma_{det} = \mathrm{diag}(\sigma_x^2,\ \sigma_y^2,\ \sigma_w^2,\ \sigma_h^2)$$

## 측정할 것

각 검출에 대해

- $s$ = 억제된 후보들의 표본 표준편차 (위치·크기 각각)
- $e$ = 그 검출과 GT 의 실제 오차 (중심 거리, 또는 1 − IoU)

그리고 **Spearman 순위상관** $\rho(s, e)$ 를 잰다.

## 판정 기준 (먼저 정하고 시작할 것)

| $\rho$ | 해석 |
|---|---|
| ≥ 0.3 | 신호가 있다. 다음 단계 진행 |
| 0.1 ~ 0.3 | 약하다. 보정(calibration) 을 붙여 재시도 |
| < 0.1 | **방향 접는다.** 다른 불확실성 소스를 찾는다 |

기준을 나중에 바꾸지 않는다.

## 데이터

- MOT17 train 절반 (CenterTrack/ByteTrack 관례의 half-half split)
- GT: `gt.txt`. 9번 열 = visibility, 8번 열 = class, 7번 열 = ignore flag
- 가림 정도별로 나눠서 보면 좋다 (visibility 구간별 $\rho$)

## 함정

- `nms_var` 계열 구현의 박스 포맷이 문서와 다를 수 있다. 참조 데이터로 직접 확인할 것
