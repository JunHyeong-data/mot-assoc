# 실험 11 (E1) — **가산 대 곱, 실데이터에서** (사전 등록)

> **자료를 보기 전에 커밋한다.** 이 실험은 원고에서 **살아남은 유일한 이론 기여**를
> 합성(`theory/threshold_and_fusion.py`, 기여 2e-16)에서 **실측**으로 옮긴다.

## 무엇을 보이려는가

원고 2절의 주장:

> **검출별 스칼라를 비용에 더하면 순수 열상수라 할당 기여가 정확히 0 이다.
> 그러므로 불확실성은 트랙과 상호작용하는 형태(곱)로 들어가야 한다.**

정독으로 확인했듯 문헌은 **예외 없이 곱**을 쓴다 (ByteTrack `fuse_score` 구현,
LG-Track 식 1·3, StrongSORT NSA Kalman 식 9) — **그런데 아무도 이유를 대지 않는다.**
그 근거를 **실데이터에서** 만든다.

## 정확한 명제 — **조건을 빼먹지 않는다**

가산 불변성은 **무조건이 아니다.** 검출별 스칼라 `u_j` 는 **열상수**이고,
열상수 불변성은 **모든 열이 정확히 한 번씩 배정될 때만** 성립한다. 즉

> **N ≤ M (검출 수 ≤ 트랙 수) 일 때만 기여가 0 이다.**

`exp00` 이 기본 설정에서 **M > N 이 지배적**이라고 실측했으므로 대부분의 호출이
이 조건을 만족할 것으로 본다. **그러나 가정하지 않고 호출마다 갈라서 센다.**

그리고 **임계값이 두 번째 예외**다. 헝가리안이 고른 쌍이 같아도
`cost ≤ match_thresh` 통과 여부가 바뀔 수 있다.

## 설계 — **같은 트래커 상태에서 셋을 나란히 푼다**

조건을 따로 돌리면 트래커 상태가 갈라져 비용함수 효과와 섞인다.
**한 번의 재생 안에서** 매 연관 호출마다 세 비용을 만들고 **셋 다 푼다**:

| 비용 | 식 |
|---|---|
| `base` | 기존 1단계 비용 (`1 − IoU·s`) |
| **`add`** | `base + a·û_j` |
| **`mul`** | `base · (1 + b·û_j)` |

`û_j` 는 검출별 σ(`sqrt(sxx+syy)`)를 프레임 안에서 `[0,1]` 로 표준화한 것.
`a` 는 **평균 `|Δcost| ≈ 0.2`** 가 되게 정한다 — 비용 범위 `[0,1]` 대비 **크다.**
`b` 는 `mul` 의 평균 `|Δcost|` 를 `add` 와 **같은 자리수로** 맞춘다.

> **요점**: 가산의 기여 0 은 **크기와 무관**하다. 그래서 **일부러 큰 섭동**을
> 주고도 할당이 한 칸도 안 움직이는 것을 보이는 것이 이 실험의 그림이다.

트래커는 `base` 로 진행한다 (관측이 개입을 안 바꾸도록).

## 사전 등록한 사전 점검

| # | 사전 점검 | 기준 |
|---|---|---|
| **[0a]** | 섭동이 실제로 크다 | `add` 의 평균 `\|Δcost\|` ≥ 0.1 |
| **[0b]** | 두 조건의 섭동 크기가 비슷하다 | `mul`/`add` 의 평균 `\|Δcost\|` 비가 0.5~2.0 |
| **[0c]** | 호출 표본 | 연관 호출 **1000건 이상** |

**[0a] 가 실패하면 판정하지 않는다** — 작은 섭동으로 "안 바뀐다" 를 보이는 것은 무의미하다.

## 사전 등록한 평가지표

| # | 평가지표 | 예측 |
|---|---|---|
| **[1]** | `N ≤ M` 호출에서 `add` 의 **임계값 전** 할당이 `base` 와 같은 비율 | **정확히 100%** |
| **[2]** | `N > M` 호출에서 같은 비율 | **100% 미만** (열이 다 안 배정됨) |
| **[3]** | `mul` 의 임계값 전 할당이 같은 비율 | **뚜렷이 100% 미만** |
| **[4]** | `add` 의 **임계값 후** 채택쌍이 다른 호출 비율 | **0 보다 크다** (임계값 경로) |

### 읽는 법 — 미리 고정한다

- **[1] 이 100% 가 아니면** → 우리 명제가 틀렸거나 구현이 틀렸다. **원고 2절을 고쳐야 한다**
- **[1] 100% 이고 [3] 이 뚜렷이 낮으면** → **설계 제약이 실데이터에서 확인된다**
- **[4] 가 0 이면** → 임계값 예외가 이 자료에서는 발현되지 않는다는 뜻. 그대로 적는다
- **[2] 는 M,N 조건의 직접 확인**이다. 100% 가 나오면 조건이 이 자료에서
  구속력이 없다는 뜻이므로 **그렇게 적는다** (명제가 틀린 게 아니다)

## 이 실험이 답하지 않는 것

- **성능이 아니다.** HOTA 는 참고로만 낸다 (`base`/`add`/`mul` 각 1회 재생)
- σ 를 섭동원으로 쓰지만 **σ 의 유용성과 무관하다.** 아무 검출별 스칼라라도 같다
- 2단계·3단계는 안 건드린다. **1단계 연관만**
