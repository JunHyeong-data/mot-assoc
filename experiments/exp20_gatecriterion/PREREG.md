# 실험 20 — **게이팅 대조군은 무엇을 맞춰야 하는가** (사전 등록)

> **자료를 보기 전에 커밋한다.**

## 왜

원고 5.3 이 게이팅 손실의 **88%** 를 *"확장량을 무엇으로 정했는가"* 에 귀속한다.
그런데 같은 절의 격자(실험 19)는 그 차이가 **사라진다**고 한다(+0.121).

| 실험 | 무엇을 맞췄나 | 검출기 σ − 박스 크기 |
|---|---|---|
| exp03 | **평균 선형 확장량(px)** | **−3.81** |
| exp19 | **총 확장 면적** | **+0.121** |

같은 것을 재지 않으므로 모순은 아니다. **그러나 어느 기준이 옳은지는 안 정했다.**
그 상태로 88% 를 원고에 두면 **기준을 고르는 자유도가 결론을 만든다.**

## 핵심 관찰 — 제3의 기준이 이미 논문 안에 있다

거리 함수 경로는 **채택률을 기준선에 맞춘다**(4.2절). 이유가 명시돼 있다 ---
비용 분포가 달라지면 채택률이 변하고, 그러면 성능 차이가 *"거리 함수의 차이"* 인지
*"채택률의 차이"* 인지 구별할 수 없기 때문이다.

**게이팅에도 똑같은 논리가 적용된다.** 상자를 키우면 IoU 가 오르고 채택률이 오른다.
따라서 **게이팅만 다른 것을 맞출 이유가 없다.**

## 무엇을 재는가

게이팅에서 `검출기 σ − 박스 크기` 를 **세 기준 각각으로** 낸다.

| 기준 | 맞추는 양 | 출처 |
|---|---|---|
| A | 평균 선형 확장량 (px) | exp03 |
| B | 총 확장 면적 | exp19 |
| **C** | **1단계 채택률** | **4.2절이 거리 함수에 쓰는 것** |

소스는 NMS 와 DFL 둘 다. 나머지는 실험 19 와 동일한 재생 틀.

## 사전 등록한 종말점

| # | 종말점 | 기준 |
|---|---|---|
| **[1]** | 기준 C(채택률)에서의 `σ − 크기` | **주 종말점** |
| [2] | 세 기준의 값 범위 | 기준 의존성의 크기 |
| [3] | 각 기준에서 실제로 맞춰졌는지 (사전 점검) | 통제 확인 |

## 판정 기준 — 자료를 보기 전에 정한다

| [2] 세 기준의 값 | 결론 |
|---|---|
| **부호가 같고 범위 < 1.5 HOTA** | 기준에 안 민감하다. **88% 주장을 유지**하되 기준 C 값으로 다시 적는다 |
| 부호는 같은데 범위 >= 1.5 | 방향은 견고하나 **크기는 기준 의존**. 88% 라는 구체적 수치를 **철회**하고 방향만 적는다 |
| **부호가 갈린다** | **88% 를 철회한다.** "확장량을 무엇으로 정했는가" 라는 귀속 자체가 기준의 산물이다 |

**주 판정은 기준 C 로 한다** --- 논문이 다른 경로에서 이미 쓰는 기준이므로
게이팅만 다르게 할 근거가 없다.

## 미리 못박는 것

- **어느 쪽이 나와도 원고에서 88% 는 조건 없이 쓸 수 없다.** 최소한 어느 기준의
  값인지 밝혀야 한다
- 사전 점검 [3] 이 실패하면(맞추기가 포화하면) **판정하지 않는다.** 실험 19 의
  첫 판이 상한 포화로 버려진 전례가 있다. 탐색 상한을 넉넉히 주고
  **목표 대비 5% 를 벗어나면 그 자리에서 멈춘다**
- n=7 이므로 시퀀스별 부호도 함께 센다 (규칙 6)

## 보정 (2026-08-20, **자료를 보기 전에 추가한다**)

심사가 셋을 지적했다. 실험이 도는 중이고 **아직 값을 읽지 않았다.**

### (1) 표적을 잘못 적었다 — 코드가 옳고 산문이 틀렸다

위 「핵심 관찰」이 *"4.2 절이 거리 함수에 쓰는 것과 같은 기준"* 이라고 적었는데
**같지 않다.**

| | 무엇에 맞추나 |
|---|---|
| 4.2 절 거리 함수 | **기준선**의 채택률 |
| 이 실험 (`run.py:116`) | **박스 크기 조건(α=0.5)**의 채택률 |

**게이팅에서는 기준선 맞춤이 원리적으로 불가능하다.** 상자를 키우면 채택률이
오르므로(이 자료에서 단조) 기준선 채택률을 주는 해는 **α≈0, 즉 "확장을 안 하는 것"
하나뿐이다.** 코드는 처음부터 박스 크기 조건에 맞추게 짜여 있었고, 산문만
4.2 절 논리를 그대로 옮겨 적어 틀렸다.

> **원칙은 옮겨가고 표적은 못 옮겨간다.** 게이팅은 **개입의 세기와 채택률이 한
> 손잡이에 묶여 있어** 기준선 대조가 원리적으로 안 잡힌다. **그 비대칭 자체가
> 원고에 적을 값어치가 있다.** 원고에서 두 경로의 통제를 "같다" 고 쓰지 않는다.

### (2) 판정 규칙에 **분모가 없었다** — 지금 박는다

사전 등록한 세 갈래는 전부 `σ − 크기`(**차이**)로 갈리는데, 88% 는 **비율**이다.

```
88% = (σ − 크기) / (σ − 기준선) = 3.81 / 4.33
```

첫 칸("범위 < 1.5 → 88% 를 유지하되 기준 C 값으로 다시 적는다")이 **어느 분모로
다시 적을지를 안 정했다.** 값을 보고 분모를 고를 자유도가 남는다. **규칙 2 가
막으려는 것이 정확히 이것이다.** 박는다:

```
88%_C = ( HOTA(σ, 기준 C) − HOTA(크기, α=0.5) )
      / ( HOTA(σ, 기준 C) − HOTA(기준선) )
```

- 박스 크기 조건은 α=0.5 로 **고정**이므로 `HOTA(크기) − HOTA(기준선)` 은
  세 기준에서 **상수**다
- 소스별로 따로 낸다 (NMS, DFL)
- **분모가 0 에 가까우면(|σ − 기준선| < 0.5 HOTA) 비율을 보고하지 않는다.**
  작은 분모가 비율을 폭발시키기 때문이다. 그 경우 차이만 적는다
- **σ 조건이 기준선보다 좋으면(분모가 양수) 비율의 뜻이 뒤집히므로 보고하지 않고
  그 사실만 적는다**

### (3) 부수 종말점 하나를 추가한다 — 채택 집합의 대칭차

기준 C 에서는 두 조건이 **같은 수의 쌍을 채택한다.** 그러면 남는 질문은
**"어느 쌍이 갈렸나"** 하나다. 두 조건의 채택 집합 대칭차를 오라클로
정답/오답 표시하면 **ΔHOTA 한 숫자가 기제로 바뀐다.**

| 결과 | 읽는 법 |
|---|---|
| 대칭차가 작다 (< 채택 쌍의 5%) | **88% 논쟁이 해소된다** — 기준이 일을 하고 있었다 |
| 대칭차가 크고 σ 쪽이 오답을 더 고른다 | 신호의 차이가 맞다 |
| 대칭차가 큰데 정답/오답 비율이 비슷하다 | 차이가 **어느 쌍인지**가 아니라 다른 데서 온다 |

이건 **부수 종말점**이다. [1] 의 판정을 대체하지 않는다.
재생만으로 되므로 [1] 이 끝난 뒤 별도로 돌린다.

### (4) 분모 가드에 **부호 조합 하나가 빠졌다**

박아 둔 가드는 둘이었다 — 분모가 0 에 가까울 때, 분모가 **양수**일 때.
**분자가 양수인데 분모가 음수인 경우**가 없다. σ 가 크기보다는 낫고
기준선보다는 나쁜 배치다.

**가상이 아니다.** 실험 19 의 기준 B 가 정확히 그 배치다:

```
σ − 크기   = +0.121      (분자, 양수)
σ − 기준선 = −6.777      (분모, 음수, 작지도 않다)
비율       = −1.8%
```

**가드 둘을 다 통과한다.** 그리고 판정표와 맞물리면 더 나쁘다 — 세 기준이 전부
작은 양수로 모이면 *"부호 같고 범위 < 1.5"* 가 발동해
**"손실의 −1.8% 가 확장량을 무엇으로 정했는가에서 온다"** 가 나온다.

> **88% 라는 서술은 "소스 선택이 손실의 지배적 원인" 을 전제한다.**
> 분자가 뒤집히면 **전제가 깨진 것**이지 비율을 고쳐 적을 일이 아니다.

**추가하는 가드:** 분자와 분모의 **부호가 다르면 비율을 보고하지 않고
귀속 문장 자체를 철회한다.** 두 차이만 적는다.

### (5) 기준 A 는 **실험 3 의 재현이 아니다 — 앵커가 반대다**

| | 무엇을 고정하고 무엇을 맞추나 |
|---|---|
| exp03 (`calibrate.py:136`) | **σ 의 α 를 고정**하고 크기를 σ 에 맞춘다 (`tx = mean_pad_sigma(...)` → `cw = tx/e_w`) |
| exp20 (`run.py:116`) | **크기를 α=0.5 로 고정**하고 σ 를 크기에 맞춘다 |

같은 양(평균 선형 확장량)을 맞추지만 **확장 크기 축 위의 다른 점에 앉는다.**
분모도 다르다 — exp03 의 −4.33 은 σ 가 **제 α 에 있을 때**의 값이고,
exp20 의 분모는 σ 를 **크기의 α=0.5 로 끌어다 맞춘** 값이다.

> **따라서 `88%_A(exp20) ≠ 88%(exp03)` 는 구성상 당연하다.**
> **A 가 −3.81 을 재현하지 못해도 그것을 exp03 의 반증으로 읽지 않는다.**
> 이 저장소가 철회 16건으로 배운 것이 정확히 그 유혹이다.

**따라 나오는 것**: 88% 는 기준뿐 아니라 **앵커(α=0.5)에도 걸려 있다.**
원고에 쓸 때 *"게이팅 경로의 성질"* 이 아니라
**"박스 크기 조건(α=0.5) 대비"** 로 범위를 붙인다.
