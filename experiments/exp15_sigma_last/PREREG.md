# 실험 15 — **σ 의 마지막 시험: 경로와 무관하게, 연관 오류를 짚는가** (사전 등록)

> **자료를 보기 전에 커밋한다.**

## 왜 이걸 이제야 묻는가

`exp01` 은 σ 가 **위치 오차**를 예측한다고 했다 (h 통제 편상관 **0.32**, 7/7 시퀀스).
그 뒤 우리는 σ 를 경로 넷에 넣어 전부 졌다 (칼만 R −0.62, 게이팅 −4.33,
거리 −4.98, 임계값 −0.21).

**그런데 그 사이의 연결고리를 한 번도 안 쟀다:**

> **σ 가 예측하는 것은 "박스가 틀렸다" 이지 "짝을 잘못 지었다" 가 아니다.**
> **σ 가 연관 오류를 짚는지는 아무도 확인하지 않았다.**

우리는 그걸 **가정하고** 경로를 갈랐다. `exp12` 의 오라클이 생겼으므로
**이제 어느 연관 결정이 틀렸는지 정확히 안다.** 경로와 무관하게 직접 묻는다.

## 무엇을 재는가

`exp12` 의 오라클 GT id 부착을 그대로 쓴다. **1단계 연관에서 실제로 채택된
(트랙, 검출) 쌍마다** 옳고 그름을 라벨한다:

| 라벨 | 정의 |
|---|---|
| **옳음** | 트랙의 GT id == 검출의 GT id |
| **틀림 (고칠 수 있음)** | GT id 가 다른데, **그 프레임에 올바른 검출이 존재**했다 |
| **틀림 (못 고침)** | GT id 가 다르고 **올바른 검출이 아예 없었다** (미검출) |
| 미상 | 검출에 GT id 가 없다 (거짓양성) |

**"고칠 수 있음" 만이 연관 방법이 손댈 수 있는 오류다.** 나머지는 검출 문제다.

그 다음, **σ 가 그 오류를 짚는지** 본다. 단위는 **채택된 쌍**이고
n 은 수만이므로 **검정력 문제가 없다** (CLAUDE.md 규칙 6).

## 사전 등록한 평가지표

| # | 평가지표 | 기준 |
|---|---|---|
| **[1]** | **AUC**(σ → 틀림(고칠 수 있음)) | **주 평가지표** |
| [2] | 박스 높이를 통제한 **편상관** (exp01 과 같은 자) | 참고 |
| [3] | 같은 것을 **박스 크기 모형 σ_C** 로 (기준 비교) | σ 가 크기를 이기는가 |
| [4] | 오류 구성 (고칠 수 있음 / 못 고침 / 미상) | 여지의 성격 |

**판정 기준 (exp01 의 사전 점검과 같은 자를 쓴다):**

| [1] AUC | 결론 |
|---|---|
| **≥ 0.60** | **σ 가 연관 오류를 짚는다.** 경로를 잘못 골랐던 것이고 **다시 볼 값어치가 있다** |
| **0.55 ~ 0.60** | 약하게 짚는다. exp01 의 0.32 가 연관까지는 잘 안 옮겨간다 |
| **< 0.55** | **σ 는 연관 오류에 대해 정보가 없다.** 어느 경로에 넣어도 안 된다. **σ 질문이 완전히 닫힌다** |

**[3] 이 [1] 보다 크면** — 여기서도 박스 크기가 이기는 것이고,
그건 exp1f 의 만장일치와 같은 이야기다. **그렇게 적는다.**

## 미리 고정하는 것

- **[1] 이 0.55 미만이어도 그건 실패가 아니라 결과다.** exp01 의 편상관 0.32 가
  **연관으로 옮겨가지 않는다**는 것이 확정되고, 경로 넷의 음성 결과가
  *"경로가 나빴다"* 가 아니라 **"애초에 옮길 정보가 없었다"** 로 설명된다.
  **그게 이 프로그램의 마지막 조각이다**
- σ 는 **DFL 분포 분산**(캐시의 `sxx`,`syy`)을 쓴다. NMS 소스는 별도 캐시가 필요해
  이번엔 안 한다 — **한계로 적는다**
- 2·3단계는 안 본다. **1단계 채택 쌍만**
