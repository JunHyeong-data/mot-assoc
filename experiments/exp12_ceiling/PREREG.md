# 실험 12 — **연관 천장.** 이 벤치마크에 애초에 몇 점이 남아 있는가 (사전 등록)

> **자료를 보기 전에 커밋한다.**

## 왜 이걸 묻는가

우리는 연관에 네 가지를 시도해 전부 음수를 얻었다
(칼만 R −0.62, 게이팅 −4.33, 거리 −4.98, 임계값 −0.21).
그때마다 **"이 경로가 나쁘다"** 로 읽었다.

**그런데 다른 설명이 있다: 애초에 딸 게 없었을 수 있다.**

실험 6 이 임계값 레버 하나에 대해 그걸 쟀다 — **오라클 상한 +0.892.**
정답을 다 알아도 1점이 안 된다. **그 계산을 레버 하나가 아니라 연관 전체로
확장한다.**

문헌 쪽 방증도 있다. UncertaintyTrack 은 **BDD100K 에서 +2.2** 를 얻었는데
거기 ByteTrack 기준선이 **mMOTA 32.5** 다. MOT17 에서는 **76.0** 이다.
**난이도가 다르고 여지가 다르다.**

## 무엇을 재는가 — **검출을 고정하고 연관만 정답으로 푼다**

```
연관 천장 = HOTA( 같은 검출, 같은 트랙 관리, **정답 연관** )
여지      = 연관 천장 − 기준선
```

**여지가 이 벤치마크에서 어떤 연관 방법이든 딸 수 있는 전부다.**

### 오라클 연관의 정의

1. 각 검출을 GT 와 **IoU ≥ 0.5** 로 맞춰 **GT id** 를 붙인다 (없으면 `None`)
2. 각 트랙은 **생성될 때 쓰인 검출의 GT id** 를 물려받아 유지한다
3. 1단계 비용을 **`0` (GT id 같음) / `1e6` (다름·없음)** 으로 바꾼다

**바꾸는 것은 1단계 연관 비용 하나뿐이다.** 검출·2단계·3단계·트랙 생성/소멸·
`track_buffer` 는 그대로다. 그래야 차이가 **연관 탓**으로만 귀속된다.

### 이 오라클이 완벽하지 **않은** 것 — 미리 적는다

- **거짓양성 검출**은 GT id 가 없어 어느 트랙과도 안 맞고 **새 트랙을 만든다.**
  그건 검출 문제이지 연관 문제가 아니므로 **고치지 않는다**
- **미검출**도 못 고친다
- 30프레임 넘게 사라진 물체는 `track_buffer` 때문에 새 트랙이 된다.
  지표상 ID switch 지만 **연관 오류가 아니다.** 그대로 둔다

> **그러므로 이건 "달성 가능한 상한" 이지 "이론적 최대" 가 아니다.**
> 실제 상한은 이보다 높을 수 있다. **낮게 잡히는 쪽이므로 보수적이다.**

## 사전 등록한 사전 점검

| # | 사전 점검 | 기준 |
|---|---|---|
| **[0a]** | 오라클이 기준선보다 **나쁘지 않다** | 천장 HOTA ≥ 기준선 HOTA |
| **[0b]** | 오라클의 **AssA** 가 뚜렷이 오른다 | AssA 상승 > 0 |
| **[0c]** | 검출 동일 | `DetA` 차이 < 1.0 (같은 캐시이므로) |

**[0a] 가 깨지면 판정하지 않는다** — 정답을 주고 나빠지면 배관이 틀린 것이다.

## 사전 등록한 평가지표

| # | 평가지표 |
|---|---|
| **[1]** | **여지** = 천장 − 기준선 (결합 HOTA, 가중 없는 평균도) |
| [2] | 같은 차이의 AssA·IDSW |
| [3] | 시퀀스별 여지 |
| [4] | 우리가 시도한 넷(−0.62 / −4.33 / −4.98 / −0.21)을 여지와 나란히 |

### 읽는 법 — 미리 고정한다

| 여지 | 결론 |
|---|---|
| **< 3 HOTA** | **이 벤치마크는 연관 포화다.** 우리 음성 결과의 상당 부분이 *"경로가 나쁘다"* 가 아니라 *"딸 게 없었다"* 로 재해석된다. **성능 논문은 여기서 못 쓴다** |
| **3 ~ 10** | 여지가 있다. 우리 방법이 그걸 못 가져온 것이다 |
| **> 10** | 여지가 크다. **연관은 여전히 열린 문제이고 우리 실패는 방법 탓이다** |

**어느 쪽이 나와도 원고에 들어간다.** 작으면 8절의 결론이 강해지고,
크면 우리 음성 결과의 한계가 분명해진다.

## 이 실험이 답하지 않는 것
